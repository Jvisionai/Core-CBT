# 문제 데이터 검토 목록

작성일: 2026-10-31

정답을 직접 풀어 보고 코드를 실행해 확인한 결과입니다. 근거가 확실한 것은 이미 고쳤고, 아래는 **원문 확인이나 출제 의도 판단이 필요해 그대로 둔 항목**입니다.

자동 검사는 `node scripts/audit_practical_answers.mjs`, `node scripts/audit_objective_answers.mjs`로 돌릴 수 있습니다(`npm test`에도 포함).

## 2. 확인이 필요한 항목

### 정답이 틀렸거나 둘 이상일 수 있음
| 데이터 | 문항 | 내용 |
|---|---|---|
| 실기 2024-2 | #20 | "RIP 기준" 최단 경로인데 정답 A-D-C-E-F는 가중치 합 기준. RIP(홉 수)면 A-D-C-F. 문구를 "비용 합 최소"로 바꾸거나 정답을 바꿔야 함 |
| 실기 2023-3 | #16 | 블랙박스 기법 고르기인데 정답이 ㄱ(동등 분할)뿐. ㄴ 경계값 분석도 블랙박스. 보기 ㄹ "Cause-Guessing"도 깨진 것으로 보임 |
| 실기 2022-1 | #3 | ㄷ 설명("자연어로 상호작용")은 NUI인데 정답은 텍스트 인터페이스 |
| SQLD 2025-1 | #16 | ROLLUP(A,B)과 다른 것: ②, ③ 모두 다름(정답 2개). ④ 보기 "①번"은 깨짐. 해설도 ②를 동등하다고 잘못 설명 |
| SQLD 2025-3 | #48 | EXCEPT vs NOT IN: ②(중복 처리)도 맞는 설명 |
| SQLD 2024-2 | #43 | ② `C1 IN (1) AND C2 IN (3,4)`도 정답과 동치 |
| SQLD 2024-2 | #8 | 발문이 잘못 복원된 듯(① "논리적 연산의 최소 단위"는 트랜잭션 정의) |
| SQLD 2024-2 | #12 | TOP WITH TIES: ④ "SQL 표준이 아님"도 사실 |
| SQLD 2024-3 | #15 | 발문에 "(복수정답)"인데 정답 1개만 저장. 1회 #14와 서로 모순 |
| SQLD 2024-3 | #12 | VIEW 독립성 기준으로는 정답 보기도 맞는 설명 |
